# Prime Number Checker

A simple Python program that checks whether an entered number is prime.

## Requirements

- Python 3

## How to Run

```bash
python prime.py
```

Enter an integer when prompted. The program will print whether the number is prime or not.

## Example

```text
Enter a number: 7
Prime number
```

## Logic

The program first rejects numbers below 2, then checks divisibility from 2 up to the square root of the entered number. If no divisor is found, the number is prime.
